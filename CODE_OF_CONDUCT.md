# Code of conduct

frads-gym follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: be respectful, assume good intent, and keep discussions about the work.

Report unacceptable behaviour to the maintainer, Silas Kalmbach (silas.kalmbach@gmail.com). Reports are
handled confidentially.
